## 一、上游 5 层 → 本项目 4 个交付字段（+1 可选）

> 下表是**默认落位，不是硬规则**（2026-11-17 明确）：哪个词进哪个字段，最终由相关性、搜索需求、产品事实和可读性共同决定。唯一硬规则是 P0 未覆盖 = FAIL（见 `05-覆盖判定.md`）。不要把「主词必须进标题、次词必须进五点」当铁律去执行。

> **字段范围**（2026-11-17 对齐项目大纲）：交付字段只有 `title` / `highlights` / `bullets` / `search_terms` 四个。`description` 是大纲外可选字段，默认不写——竞品 `description` 字段全为 null，无对标样本。下表中提到"描述"的位置，写作时改由五点承接。

| 层级 | 名称 | 建议位置（上游 L63-69） | 本项目字段 |
|---|---|---|---|
| L1 | 核心品类词 | Item Name 开头 + 亮点放**同义词变体** + 五点 | `title` 开头，`highlights` 放变体 |
| L2 | 功能属性词 | Item Name 关键差异 + 亮点 + **五点 1** | `title` 差异位 + `bullets[0]` |
| L3 | 场景词 | 主场景进 Item Name 或亮点 + 次场景进亮点 + **五点 3** | `highlights` 主 + `bullets[2]` |
| L4 | 问题词 | 亮点（简短价值短语）+ 五点 + QA + A+ | `bullets` 痛点位 |
| L5 | 规格词 | Item Name + 亮点（包装内容）+ **五点 4** | `title` 规格位 + `bullets[3]` |

> **「标题规格位」的准确含义**（2026-11-17 澄清）：指**变体规格槽**——服装尺码（`M / Large`）、多件套件数（`2 Pack`）、容量（`16 oz`）这类变体属性。
> **产品尺寸不是标题规格位**。服装类目之外的单一 SKU，标题里没有规格槽可填，尺寸只进五点的适配说明。
> 本产品（单件、非服装）→ **标题无规格位**，L5 只走 `bullets[3]`（五点第 4 位的包装内容）与亮点。

上游另有一条硬约束（L71）：

> 标题缩减到 75 字符后，放不下的 P0 词优先挪到 Item Highlights（官方确认可搜索索引），不要硬塞标题。

**这条优先于本文件任何排序。** 标题超 75 时，先挪词到亮点，不是砍词。

字段级字段名（上游 L87-89）：`suggested_position` / `must_frontend` / `priority`。本项目词库 `keyword_library.csv` 用 `prio` 承载 priority，没有 `must_frontend` 列，用 `prio == P0` 等价替代。

## 二、本项目已定的三条判定口径（上游未写）

这三条是 2026-11-16 冲突裁决的结果，来自用户对 16 条冲突的逐条拍板。

### 1. 一义一词：差集新实义词 ≥1 才占词位

同一字段里两个词若存在包含关系，判断后者是否值得占位：

- 去掉停用词与介词后，**后者比前者多出至少 1 个实义词** → 占词位
- 只多了介词（`in` / `for` / `with`）→ **不占词位**，允许作为自然包含存在

例：`sponge holder` vs `in sink sponge holder` → 后者只多介词，不占位；`sponge holder` vs `sink sponge holder with suction cups` → 多了 `suction` / `cups`，占位。

依据：用户埋词 SOP 的 P5（允许词序、单复数、介词调整）。

### 2. 超长先压缩，再按序砍

标题超 75 的处理顺序：

1. **共享词干压缩**：复用已在标题里的词干（`holder` / `sponge` / `sink`），不重写整词
2. 压完仍超 → 从右往左砍，**先砍规格、再砍场景**
3. 永不砍：核心品类词、R≥0.6 的差异属性

### 3. 取词双闸门

进入标题/亮点的词必须同时满足：

- 在 `prio` 名额内（P0 全取，P1 按 W 降序取）
- `R ≥ 0.6`

两条都过才可用。只过一条不取。

## 四、不要做的事

1. **不要按 W 降序把词硬填满每个字段**。上游 L71 明确写了不要硬塞标题，同一逻辑适用于五点。
2. **不要把 L4 问题词当 L1 核心词用**。`won't fall off` 这类是买家语言，放 `title` 会读着像广告语。
3. **不要让同一整短语横跨两个字段**。见 `02-埋词原则.md` 的重叠阈值。
