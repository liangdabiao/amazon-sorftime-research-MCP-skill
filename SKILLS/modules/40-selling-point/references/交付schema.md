# 交付 schema

七张 CSV + 一个 xlsx。所有表第一列或前两列是主键，可互相 join。

## SP-01-卖点库.csv（主表）

一行一个卖点。

| 列 | 类型 | 说明 |
|---|---|---|
| `sp_id` | 文本 | SP01 起编，唯一 |
| `卖点名` | 文本 | 中文短语，≤12 字 |
| `英文主张` | 文本 | ≤8 词，可直接进五点 |
| `类型` | 枚举 | 功能 / 结构 / 材质 / 外观 / 场景 / 价值 / 信任 |
| `关联L1` | 文本 | 斜杠分隔，取值必须是 `30-insight` 的 19 个 L1 |
| `五点覆盖` | 0-1 | 命中 ASIN 数 ÷ 样本数 |
| `覆盖ASIN数` | 整数 | 与证据链去重后的 ASIN 数一致（自检第 6 项） |
| `平均位次` | 小数 | 命中的五点在原文里的平均位置 |
| `好评验证条数` | 整数 | V 的原始计数 |
| `差评条数` | 整数 | P 的分子 |
| `差评占比` | 0-1 | 差评条数 ÷ 差评总数 |
| `支撑词` | 文本 | `词(W)` 形式，分号分隔；没有就写"无直接搜索词" |
| `S` / `P` / `V` / `D` | 0-1 | 四个分量 |
| `M` | 0-100 | 文案排序分 |
| `G机会分` | 0-1 | 定级分 |
| `角色` | 枚举 | 入场券 / 主攻空白 / 常见卖点 / 已验证卖点 / 品类标配 / 待验证 / 淘汰 |
| `等级` | 枚举 | A / B / C / D |
| `证据维度` | 0-3 | 有几维证据（五点/评论/图片） |
| `冲突` | Y/空 | 是否进冲突表 |
| `冲突类型` | 枚举 | 品类级反噬 / 声称与体验背离 / 痛点未解决 / 空 |
| `confidence` | 枚举 | MEASURED / DERIVED / JUDGED |
| `备注` | 文本 | 名额顺延、门槛未达等说明 |

## SP-02-证据链.csv（长表）

一行一条证据。这张表是"能不能回查"的关键，自检第 7 项直接读它。

| 列 | 说明 |
|---|---|
| `sp_id` / `卖点名` | 关联主表 |
| `维度` | 五点 / 评论 / 图片 |
| `来源类型` | `asin_detail.features` / `amz-review-analysis` / `image_pack` |
| `来源文件/sheet` | 具体文件与 sheet 名 |
| `定位` | 五点写 `<ASIN>#<第几点>`；评论写 `<一级>\|<二级>`；图片写 `<ASIN>_<位次>` |
| `原文/计数` | 五点存原文前 300 字；评论存"好评 X 条 / 差评 Y 条" |
| `n` | 该条证据的计数 |
| `confidence` | 同上 |

## SP-03-五点拆解矩阵.csv

`ASIN | 品牌 | 安装形态 | 命中卖点数 | SP01..SPnn`。单元格写 `SP01(2,4)` 表示这个 ASIN 在第 2、4 点写了该卖点，空表示没写。安装形态取 `吸盘 / 胶粘 / 挂龙头隔板`。

## SP-04-图片降级清单.csv

`sp_id | 卖点名 | 应承载图位 | 应有画面 | 当前状态 | 补图后可验证什么`。

图包到位后本表被真实拆解替换，`当前状态` 改成实际观察到的画面。

## SP-05-评论映射.csv

`sp_id | 卖点名 | 一级 | 二级 | 好评条数 | 差评条数 | 合计`。二级名必须与 `04_二级频次` 完全一致，差一个字就匹配不上。

## SP-06-冲突与风险.csv

`sp_id | 卖点名 | 五点覆盖 | 差评占比 | 冲突分 | 类型 | 对撞证据 | 风险说明 | 处置建议`。

`冲突分 = cov × P × 100`，用于排序。对撞证据写 `二级(条数)` 形式。

## SP-07-待补证据.csv

只收 C 级和 D 级。`sp_id | 卖点名 | 当前等级 | 缺什么证据 | 补证动作 | 补到哪一维`。

## 卖点库.xlsx

八个 sheet，与上面七张表一一对应，加一张 `00_说明`（口径、权重定义、等级规则、已知限制）。

格式约定：首行深蓝底白字、冻结首行、自动筛选、等级列条件填色（A 绿 / B 黄 / C 橙 / D 灰）。

## 命名与位置

默认落在 `调研/<类目>/selling-point/`。文件名固定带 `SP-` 前缀，方便和 `10-keyword` 的 `00~08` 编号区分。
