# 04 · 禁用表

> **词表真源在 `skills/scripts/copy_config.yaml` 的 `disallowed` 段，本文件不重复维护词表。**
> 这里只解释：为什么禁、禁到什么程度、命中后怎么改。两处都写词表必然漂移——`_common/政策边界.md:77` 那句「不要只改一处，AI 会随机挑一个执行」说的就是这个坑。

三张表，三档处置：

| 表 | 内容 | 命中判定 |
|---|---|---|
| `redline` | 合规红线（绝对化 / 医疗 / 环保 / 安全 / 排名 / 价格） | **FAIL** |
| `ai_cliche` | 营销腔（unleash / elevate / seamlessly …） | **FAIL** |
| `vague` | 无证据的形容词（premium quality / easy to use …） | **WARN** |

另有一张品类级 `categories.<品类>.forbidden`，由事实卡决定，命中 **FAIL**。

---

## 一、redline：合规红线

来源：`modules/_common/政策边界.md` 第一节，与上游 `prompts/compliance-check-prompt.md:138-152` 的红线词表一致。

| 类型 | 典型词 | 为什么禁 | 怎么改 |
|---|---|---|---|
| 绝对化 | `100%` `never` `always` `guaranteed` | 声称不可验证，亚马逊要求可在包装上验证 | `help reduce` / `designed to` / `supports` |
| 医疗功效 | `cures` `treats` `heals` | 家居品类无医疗资质 | `supports` / `may help` |
| 环保绝对 | `eco-friendly` `biodegradable` `organic` | 无认证不得声称 | `made with recyclable materials` |
| 安全承诺 | `FDA approved` `non-toxic` `chemical-free` | 无认证不得声称 | `meets [实际标准]` |
| 持久承诺 | `lifetime` `forever` | — | `long-term use` |
| 夸大排名 | `best` `#1` `top rated` `best seller` | — | `popular` / `favored` |
| 价格绝对 | `cheapest` `lowest price` | — | `affordable` / `value` |
| 功能绝对 | `waterproof` `fireproof` | 无实测数据不得声称 | `water-resistant`（如有测试） |
| 抗菌消毒 | `antibacterial` `antimicrobial` `sanitizes` `kills 99` | 无第三方检测报告不得声称 | 只写可验证的材质与结构 |
| 比较级宣称 | `better than` `more durable than` `stronger than` `lasts longer than` `outperforms` | 无法验证的比较声明，官方要点 requirements 页明列 | 写自己的具体参数，不拉对手比 |

> 功能、抗菌两类是本品的高危项：事实卡 `load.tested = false`，说明没有任何实测数据。所以不但 `waterproof` 不能写，**任何 `lbs` 数值也不能写**——这条由 `check_copy.py` C9 单独守卫。

## 二、ai_cliche：营销腔

来源：用户埋词 SOP 的 P1「Natural English expression takes priority」。上游只有 4 个空话词（`compliance-check-prompt.md:92-94`），不够用，本表是补充。

三类最典型：

| 类型 | 例子 | 问题 |
|---|---|---|
| 动词化夸张 | `unleash` `elevate` `transform your` `upgrade your` | 买家不知道你做了什么，只知道你在夸 |
| 副词糖精 | `seamlessly` `effortlessly` `hassle-free` | 无信息量，且是 AI 默认语料 |
| 句式套话 | `say goodbye to` `look no further` `the perfect solution` `take it to the next level` | 模板句，读三遍都记不住产品 |

改法只有一条：**换成具体动作或具体条件**。

- ✗ `effortlessly organize your sink` → ✓ `holds a sponge and a brush without drilling`
- ✗ `unleash a cleaner kitchen` → ✓ `keeps the sponge off the counter`

## 三、vague：无证据的形容词

来源：`compliance-check-prompt.md:92-94` + `common-mistakes.md:79-85`。

| 空话 | 应该写 |
|---|---|
| `premium quality` | 写具体材料（`PC body`） |
| `perfect for any occasion` | 写具体 2-3 个场景 |
| `easy to use` | 写具体怎么用（`three steps, no tools`） |
| `great gift` | 写适合谁 |

判 WARN 不判 FAIL 的理由：这些词本身不违规，但占掉了可以说事实的位置。**命中就说明有一句废话可以换成证据。**

---

## 三·补、promo：促销与卖家信息（2026-11-17 补）

来源：官方标题指南 `GYTR6SYGFA5E3EQC`——标题不得含促销语与卖家信息。要点指南同口径，所以**五点和描述也不写**。

| 类别 | 词表（`copy_config.yaml` → `disallowed.promo`） |
|---|---|
| 运费/赠品 | `free shipping` `free delivery` `free gift` |
| 促销/时限 | `on sale` `for sale` `limited time` `clearance` `while supplies last` `new arrival` `hot deal` |
| 行动号召 | `buy now` `order now` `click here` |
| 价格/承诺 | `best price` `money back` `satisfaction guaranteed` `bestseller` `best-selling` `hot item` |
| 卖家信息 | 店名、邮箱、URL、电话（C12 用正则拦） |

判 **FAIL**，因为这是官方明列禁项，不是风格问题。已被 `redline` 覆盖的 `best seller` / `top rated` / `guaranteed` 不重复列在这里。

## 三·补2、占位、缩写、emoji（2026-11-17 补）

来源：官方要点 requirements 页 `GX5L8BF8GLMML6CX` 的禁止清单。

| 类别 | 词/字符（`copy_config.yaml` 对应段） | 为什么禁 | 级别 |
|---|---|---|---|
| 占位内容 | `n/a` `tbd` `to be determined` `coming soon`（`disallowed.placeholder`） | 买家看到 `TBD` 等于没写，官方明列禁项 | FAIL |
| 不必要缩写 | `qty` `pkg` `w/` `approx.` `incl.` `ea.`（`disallowed.abbrev`） | 省不了几个字符，却让非母语买家多一道解码 | WARN |
| emoji | 所有 emoji 与图形符号（`structure.frontend_forbid_emoji`） | 官方明列禁项，且部分设备渲染成方块 | FAIL |

**为什么缩写是 WARN 不是 FAIL**：官方把它列在「避免」而非「不得」，且 `w/` 这类在五点里偶尔是唯一不别扭的写法。判 WARN 是提示「这里有更好的写法」，不是必须改。

**emoji 为什么单列**：原来的「非拉丁字符」检查只对标题、且判 WARN。emoji 是官方明列禁项、适用全字段，所以单独出来判 FAIL。

## 四、品类级禁写（由事实卡决定）

这部分不是通用规则，必须每品类从事实卡推。以 sponge-holder 为例（配置里已有）：

| 禁写 | 理由 | 依据 |
|---|---|---|
| `soap` | 分区只有海绵位 + 刷位，**无皂位** | `00-事实卡.json` `structure.zone_use` |
| `dishwasher safe` | 无耐温与洗碗机测试数据 | 事实卡无对应字段 |
| `rustproof coating` | 主体是 PC 塑料，无涂层可掉 | 原措辞来自竞品金属件 |

连带影响：`dish soap holder` / `soap holder kitchen` / `sink soap holder` 三个词库词（合计 10,734 搜索量）**全部作废，不得进任何字段**。这条在卖点库 v2 定稿时已经暴露过一次——`SP11` 原 claim 写了 `soap`，是臆造。

## 五、命中后怎么处理

| 命中表 | 处理 | 不许做的事 |
|---|---|---|
| `redline` | 必改，改完重跑 | 不许用同义红线词替换（`100%` → `completely` 一样违规） |
| `ai_cliche` | 必改，换具体动作 | 不许只删词留空句 |
| `vague` | 建议改，换证据 | 不许改成一个更长的空话 |
| 品类禁写 | 必改，且要回查卖点库 | 不许只改文案不改卖点库（否则下一轮又写回来） |

最后一条是实战教训：`soap` 那次就是卖点库和文案两处不同步，改了文案没改库，下一版又会冒出来。
